   с 22:31 UTC не больше 1 запроса в 2 секунды, паузы 20–40 с после 503, 15 минут после серии, остановка после 3 часов сплошных 503.
2. Данные источника (ссылки, закупочные цены, артикулы, отчёты) вынесены в `sources/` вне Git. Коммит этапа 2, где они были,
   я пересобрал локально **до первого push** (силовой push не понадобился) — в GitHub они не попали.
3. Наша стоимость доставки считается по стоимости заказа **у источника** (сумма закупки), а не по нашей цене продажи.
4. Фото цветов: сайт источника отдаёт их обычным публичным запросом (разрешён robots.txt). Если этот запрос 5 раз подряд не отвечает,

   страницы, которые мы уже скачивали днём (сайт отдаёт их из своего кэша, до сервера источника запрос не доходит).
